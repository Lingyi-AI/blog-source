### 必备部分
``` CSharp
try
{
    // 希望进行异常捕获的代码块
    // 放到try中
    // 如果try中的代码  报错了  不会让程序卡死
}
catch
{
    // 如果出错了  会执行  catch中的代码  来捕获异常
    // catch(Exception e) 具体报错跟踪  通过e得到  具体的错误信息
}
```

### 可选部分
``` CSharp
finally
{
    // 最后执行的代码  不管有没有出错  都会执行其中的代码
    // 目前  大家可以不用写
}
```

注意：异常捕获代码基本结构中  不需要加； 在里面去写代码逻辑时  每一句代码才加；
