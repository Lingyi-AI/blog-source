算数运算符  是用于  数值类型变量计算的运算符
它的返回结果是数值

### 知识点一 赋值符号
关键知识点：
先看右侧再看左侧，把右侧的值赋值给左侧的变量

``` CSharp
string myName = "唐老狮";
int myAge = 18;
```


### 知识点二 算数运算符

#### 加 +

``` CSharp
// 用自己计算，先算右侧结果再赋值给左侧变量
// 3
i = i + 2;
// 连续运算，先算右侧结果再赋值给左侧变量
// 99
i = 1 + 3 + 89;
// 4
i = 1 + 2 + 1;
// 初始化时就运算，先算右侧结果再赋值给左侧变量
int i2 = 1 + 2 + 4;
```

#### 减 -

``` CSharp
// 用自己计算 先算右侧结果再赋值给左侧变量
int j = 1;
j = j - 1;
// 连续运算 先算右侧结果再赋值给左侧变量
j = 1 - 2 - 3;
j = 1 - j;
Console.WriteLine(j); // 5
// 初始化时就运算 先算右侧结果再赋值给左侧变量
int j2 = 1 - j - 0;
```

#### 乘 *

``` CSharp
// 用自己计算 先算右侧结果再赋值给左侧变量
int c = 1;
c = c * 10;
// 连续运算 先算右侧结果再赋值给左侧变量
c = 1 * 2 * 3;
c = 2 * c * 2;
// 初始化时就运算 先算右侧结果再赋值给左侧变量
int c2 = c * 2;
```

#### 除 /

``` CSharp
// 用自己计算  先算右侧结果  再赋值给左侧变量
int chu = 1;
chu = 10 / chu;
// 连续运算  先算右侧结果再  赋值给左侧变量
// 初始化时就运算  先算右侧结果  再赋值给左侧变量
chu = 1;
chu = 1 / 2;
// 默认的整  数是int 如果用来做除法运算 要注意 会丢失小数点后的小数
// 如果你想用浮点数来存储  一定是  在运算时要有浮点数的特征
float f = 1 / 2f;
Console.WriteLine(f);
```

#### 取余 %

``` CSharp
// 用自己计算 先算右侧结果再赋值给左侧变量
int y = 4;
// 4/3 得到余数 1
y = y % 3;
// 连续运算 先算右侧结果再赋值给左侧变量
y = 4 % 3 % 2;
// 初始化时就运算 先算右侧结果再赋值给左侧变量
```

### 知识点三 算数运算符的优先级

优先级是指在混合运算时的运算顺序
乘除取余优先级高于加减，先算乘除取余后算加减
``` CSharp
int a = 1 + 2 * 3 / 2 + 1 + 2 * 3;
a = 1 + 4 % 2 * 3 / 2 + 1;
// 括号可以改变优先级，优先计算括号内内容
a = 1 + 4 % (2 * 3 / 2) + 1;
// 多组括号，先算最里层括号，依次往外算
a = 1 + (4 % (2 * (3 / 2))) + 1;
```

### 知识点四 算数运算符的复合运算符

``` CSharp
// 固定写法运算符
// +=  -=  *=  /=  %=
// 复合运算符是用于自己=自己进行运算
int i3 = 1;
i3 = i3 + 2;

i3 = 1;
i3 += 2; // i3 = i3 + 2;
```

### 知识点五 算术运算符的  自增减   ++默认加1...

``` CSharp
int a2 = 1;
a2 = a2 + 1;

a2 = 1;
a2 += 1;

// 自增运算符
a2 = 1;
a2++; // 先用再加
Console.WriteLine(a2);

++a2; // 先加再用
Console.WriteLine(a2);

a2 = 1;
Console.WriteLine(a2++); // 1
// 2
Console.WriteLine(++a2); // 3
```
