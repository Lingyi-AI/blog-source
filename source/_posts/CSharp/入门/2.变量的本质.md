### 变量的本质
>// 变量的本质是2进制 ——> 计算机中所有数据的本质都是二进制  是一堆0和1
// 为什么是2进制？
// 数据传递只能通过电信号，只有开和关两种状态。所以就用0和1来表示这两种状态
// 计算机中的存储单位最小为bit（位），他只能表示0和1两个数字
// 1bit就是1个数 要不是0 要不是1
// 为了方便数据表示
// 出现一个叫byte（字节）的单位，它是由8个bit组成的存储单位
// 所以我们一般说一个字节为8位
// 1 byte = 0000 0000

// 2进制和10进制的对比
// 2进制和10进制之间的相互转换

2进制转10进制的规则  
从右往左看，最右边的一位为第0位  
如果该位不为0，则加上2的n位次方
