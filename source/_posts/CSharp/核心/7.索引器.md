### 知识点一 索引器基本概念

基本概念
让对象可以像数组一样通过索引访问其中元素，使程序看起来更直观，更容易编写


### 知识点二 索引器语法

``` CSharp
//访问修饰符 返回值 this[参数类型 参数名，参数类型 参数名......]
//{
// 	内部的写法和规则和索引器相同
// 	get{}
// 	set{}
//}
```

``` CSharp
class Person
{
    private string name;
    private int age;
    private Person[] friends;

    public Person this[int index]
    {
    	get
    	{
    		return friends[index];
    	}
   	 set
    	{
    		//value代表传入的值
    		friends[index] = value;
    	}
    }
}
```


### 知识点三 索引器的使用

``` CSharp
Person p = new Person();
p[0] = new Person();
Console.WriteLine(p[0]);
```


### 知识点四 索引器中可以写逻辑

``` CSharp
public Person this[int index]	//(get/set和成员属性差不多)
{
    get
    {
    	//可以写逻辑的 根据需求来处理这里面的内容
    	return friends[index];
    }

    set
    {
    	//value代表传入的值
    	//可以写逻辑的 根据需求来处理这里面的内容
   	 friends[index] = value;
    }
}
```


### 知识点五 索引器可以重载

``` CSharp
//重载的概念是一函数名相同 参数类型、数量、顺序不同
public int this[int i, int j]	//(在[]里写参数,用的时候在[]里填参数,可以写多个但要满足重载)
//(通过this[]里的参数来判断重载)
{
    get
    {
    return array[i, j];
    }
    set
    {
    array[i, j] = value;
    }
}
```

---
总结
索引器对于我们来说的主要作用
可以让我们以中括号的形式范围自定义类中的元素 规则自己定 访问时和数组一样
比较适用于 在类中有数组变量时使用 可以方便的访问和进行逻辑处理

固定写法
访问修饰符 返回值 this[参数列表]
get和set语句块
可以重载

注意：结构体里面也是支持索引器
