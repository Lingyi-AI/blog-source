### 知识点一 字符串指定位置获取

``` CSharp
//字符串本质是char数组
string str = "唐老狮";  //  (字符串第一个位置从0开始)
Console.WriteLine(str[0]);
//转为char数组
char[] chars = str.ToCharArray();
Console.WriteLine(chars[1]);

for (int i = 0; i < str.Length; i++)
{
    Console.WriteLine(str[i]);
}
```

### 知识点三 正向查找字符位置	(IndexOf)

``` CSharp
str = "我是唐老狮！";
int index = str.IndexOf("唐");  //  (可以查找多个字，查找到返回第一个的位置)
Console.WriteLine(index);  //2
	//  (查找字符位置，如果没找到则返回-1)
index = str.IndexOf("吊");
Console.WriteLine(index);  //-1
#endregion
```


### 知识点四 反向查找指定字符串位置	(LastIndexOf)

``` CSharp
str = "我是唐老狮唐老狮";

index = str.LastIndexOf("唐老狮");
Console.WriteLine(index);  //2
	//  (从反方向开始查找，和正向查找差不多方向相反)
index = str.LastIndexOf("唐老师");
Console.WriteLine(index);  //-1
```


### 知识点五 移除指定位置后的字符	(Remove)

``` CSharp
str = "我是唐老狮唐老狮"
str.Remove(4);  //  (包含指定位置)
Console.WriteLine(str);
str = str.Remove(4);  //  (移除后不会改变原字符，需要通过存储或赋值)
Console.WriteLine(str);  //  (string中很多方法都是需要通过存储或赋值的)

//执行两个参数进行移除
//参数1 开始位置
//参数2 字符个数
str = str.Remove(1, 1);
Console.WriteLine(str);
```

练习题：
在 C# 中，string 与 String、int 与 Int32、short 与 Int16、long 与 Int64 等类型实际上是 完全等价的。

string = System.String
int = System.Int32
short = System.Int16
long = System.Int64


小写 = C# 关键字（语法糖）
大写 = .NET 系统真正的类名
它们完全等价，编译后一模一样
日常写代码：全部用小写！
string 不要写 String
int 不要写 Int32
bool 不要写 Boolean


练习题：
编写一个函数，将输入的字符串反转。不要使用中间商，你必须原地修改输入数组。交换过程中不使用额外空间
比如：输入 { ‘h’, ‘e’, ‘l’, ‘o’ } 输出 { ‘o’, ‘l’, ‘e’, ‘h’ }

题目要求原地修改字符数组实现反转，且交换时不使用额外空间（即不用临时变量）。
核心方法：
1.用双指针：左指针从 0 开始，右指针从数组末尾开始
2.交换左右指针指向的字符，直到两指针相遇
3.交换时用算术运算 / 异或实现无临时变量交换	//(方式1：异或交换 ,  方式2：加减交换)

``` CSharp
public void BBB(string str) 
{
    char[] c = str.ToCharArray();
    int j = c.Length-1;
    for (int i = 0; i < j; i++)
    {
        c[i] = (char)(c[i] + c[j]);  	//(加减交换是通过char转为ASCII进行交换位置的)
        c[j] = (char)(c[i] - c[j]);	//(异或交换是通过char转ASCII再转二进制进行交换位置的)
        c[i] = (char)(c[i] - c[j]);	//(难点，异或交换)
        j--;
    }
    for (int i = 0; i < c.Length; i++) 
    {
        Console.Write(c[i]);
    }
}
```

异或交换核心代码：
c[i] ^= c[j];	//char转ASCII再转二进制然后进行异或运算
c[j] ^= c[i];
c[i] ^= c[j];
