### 知识回顾
string是特殊的引用
每次重新赋值或者拼接时会分配新的内存空间
如果一个字符串经常改变会非常浪费空间


### 知识点 StringBuilder
C#提供的一个用于处理字符串的公共类
主要解决的问题是：
修改字符串而不创建新的对象，需要频繁修改和拼接的字符串可以使用它，可以提升性能
使用前 需要引用命名空间	(using System.Text)


### 初始化 直接指明内容

``` CSharp
StringBuilder str = new StringBuilder("123123123");
Console.WriteLine(str);
```


### 容量

``` CSharp
//StringBuilder存在一个容量的问题，每次往里面增加时会自动扩容	(每次扩容自身的两倍，16*2 )
//获得容量
Console.WriteLine(str.Capacity);
 
//获得字符长度
Console.WriteLine(str.Length);
```


### 增删查改替换


#### 增
``` CSharp
str.Append("4444");
Console.WriteLine(str);
Console.WriteLine(str.Length);
Console.WriteLine(str.Capacity);

str.AppendFormat("{0}{1}", 100, 999);
Console.WriteLine(str);
Console.WriteLine(str.Length);
Console.WriteLine(str.Capacity);
```

#### 插入
``` CSharp
str.Insert(0, "唐老狮");
Console.WriteLine(str);
```

#### 删
``` CSharp
str.Remove(0, 10);
Console.WriteLine(str);
```

#### 清空
``` CSharp
str.Clear();
Console.WriteLine(str);
```

#### 查
``` CSharp
Console.WriteLine(str[1]);
```

#### 改
``` CSharp
str[0] = 'A';
Console.WriteLine(str);
```

#### 替换
``` CSharp
str.Replace("1", "唐");
Console.WriteLine(str);
```

``` CSharp
//重新赋值 StringBuilder
str.Clear();
str.Append("123123");
Console.WriteLine(str);
//判断StringBuilder是否和某一个字符串相等
if( str.Equals("12312"))
{
    Console.WriteLine("相等");
}
```
