### 知识点一 基本概念

一个类A继承一个类B		(A类继承B类,A类就有了B类的成员属性成员方法等)
类A将会继承类B的所有成员  
A类将拥有B类的所有特征和行为  

被继承的类  
称为 父类、基类、超类  

继承的类  
称为子类、派生类  

子类可以有自己的特征和行为  

特点  
1.单根性 子类只能有一个父类	(在C#中一个类只能继承一个类)
2.传递性 子类可以间接继承父类的父类	(最末端的子类可以继承顶层父类)

### 知识点三 实例

``` CSharp
class Teacher
{
    //姓名
    public string name;
    //职工号
    public int number;
    //介绍名字
    public void SpeakName()
    {
    	Console.WriteLine(name);
    }
}

class TeachingTeacher : Teacher
{
    //科目
    public string subject;
    //介绍科目
    public void SpeakSubject()
    {
        Console.WriteLine(subject + "老师");
    }
}

//使用
TeachingTeacher tt = new TeachingTeacher();
tt.name = "唐老狮";
tt.number = 1;
tt.SpeakName();

tt.subject = "Unity";
tt.SpeakSubject();
```


### 知识点四 访问修饰符的影响

public - 公共 内外部访问
private - 私有 内部访问	(子类使用父类的成员属性方法受访问修饰符的影响)
protected - 保护 内部和子类访问

之后讲命名空间的时候讲
internal - 内部的 只有在同一个程序集的文件中，内部类型或者是成员才可以访问


### 知识点五 子类和父类的同名成员	(同名时会把父类的成员覆盖掉)
概念
C#中允许子类存在和父类同名的成员
但是  极不建议使用
