### 知识点一 var隐式类型

``` CSharp
//var是一种特殊的变量类型
//它可以用来表示任意类型的变量
//注意：
//1. var不能作为类的成员 只能用于临时变量申明时
// 也就是 一般写在函数语句块中
//2. var必须初始化

var i = 5;
var s = "123";
var array = new int[]{ 1, 2, 3, 4 };
var list = new List<int>();
```

### 知识点五 可空类型

``` CSharp
//1.值类型是不能赋值为 空的
//int c = null;
//2.申明时 在值类型后面加？ 可以赋值为空
int? c = 3;
//3.判断是否为空
if( c.HasValue )
{
	Console.WriteLine(c);
	Console.WriteLine(c.Value);
}
//4.安全获取可空类型值
int? value = null;
// 4-1.如果为空 默认返回值类型的默认值
Console.WriteLine(value.GetValueOrDefault());
// 4-2.也可以指定一个默认值
Console.WriteLine(value.GetValueOrDefault(100));


object o = null;	//引用类型
if( o != null )
{
    Console.WriteLine(o.ToString());
}
//相当于是一种语法糖 能够帮助我们自动去判断o是否为空
//如果是null就不会执行tostring也不会报错
Console.WriteLine(o?.ToString());


int[] arrryInt = null;

Console.WriteLine(arrryInt?[0]);

Action action = null;	//委托
//if (action != null)
//{
//    action();
//}
action?.Invoke();
```


### 知识点六 空合并操作符

``` CSharp
// 空合并操作符 ??
// 左边值 ?? 右边值
// 如果左边值为null 就返回右边值 否则返回左边值
// 只要是可以为null的类型都能用

int? intV = null;
//int intI = intV == null ? 100 : intV.Value;
int intI = intV ?? 100;
Console.WriteLine(intI);

string str = null;
str = str ?? "hahah";
Console.WriteLine(str);
```


### 知识点七 内插字符串

``` CSharp
//关键符号：$
//用$来构造字符串，让字符串中可以拼接变量
string name = "唐老狮";
int age = 18;
Console.WriteLine($"好好学习,{name},年龄: {age}");
```
