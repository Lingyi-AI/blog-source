### 知识点二 单选框

``` CSharp
//单选框是基于 多选框的实现
//关键：通过一个int标识来决定是否选中	//nowSelIndex是外部int变量
if(GUI.Toggle(new Rect(0, 100, 100, 30), nowSelIndex == 1, "选项一"))
{
	nowSelIndex = 1;
}
if(GUI.Toggle(new Rect(0, 140, 100, 30), nowSelIndex == 2, "选项二"))
{
	nowSelIndex = 2;
}
if(GUI.Toggle(new Rect(0, 180, 100, 30), nowSelIndex == 3, "选项三"))
{
	nowSelIndex = 3;
}
```
