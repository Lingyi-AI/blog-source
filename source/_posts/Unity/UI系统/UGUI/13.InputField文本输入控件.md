### 知识点一 InputField是什么

InputField是输入字段组件
是UGUI中用于处理玩家文本输入相关交互的关键组件

默认创建的InputField由3个对象组成
父对象——InputField组件依附对象 以及 同时在其上挂载了一个Image作为背景图
子对象——文本显示组件（必备）、默认显示文本组件（必备）

### 知识点四 监听事件的两种方式

#### 2022版本有三个列表，其中多的一个是On Submit 只有按回车才触发

#### 1.拖脚本

#### 要选择的是动态的，函数是要有一个string参数的，private私有的函数找不到不能拖

#### 2.代码添加

#### 函数里的string 相当于组件参数 Text

``` CSharp
InputField inputF = GetComponent<InputField>();
inputF.onValueChanged.AddListener((str) => 
{
    print("改动时触发" + str);
});
inputF.onSubmit.AddListener((str) => 
{
    print("回车时触发" + str);
});
inputF.onEndEdit.AddListener((str) => 
{
    print("结束输入时触发" + str);
});

public void inputfield1(string str) 
{
    print(str);
}
```

``` CSharp
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.UI;

public class InputFieldxiti : MonoBehaviour
{
    //输入改名面板
    public GameObject obj;
    //确定改名按钮
    public Button but2;
    //输入改名文本控件
    public InputField InputField;
    //显示名字text
    public Text PlayerName;
    void Start()
    {
        //挂载到了改名按钮上的
        Button but = GetComponent<Button>();
        //显示输入改名面板
        but.onClick.AddListener(activeself);
        //点击确定改名逻辑
        but2.onClick.AddListener(() => 
        {
            if (InputField.text != "") 
            {
                PlayerName.text = InputField.text;
            }
            obj.SetActive(false);
        });
    }
    public void activeself() 
    {
        obj.SetActive(true);
    }
}
```
