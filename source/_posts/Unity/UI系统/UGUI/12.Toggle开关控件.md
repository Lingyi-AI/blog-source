### 知识点一 Toggle是什么

Toggle是开关组件
是UGUI中用于处理玩家单选框多选框相关交互的关键组件

开关组件 默认是多选框
可以通过配合ToggleGroup组件制作为单选框

默认创建的Toggle由4个对象组成
父对象——Toggle组件依附
子对象——背景图（必备）、选中图（必备）、说明文字（可选）

### 知识点三 代码控制

``` CSharp
ToggleGroup toggleGroup = GetComponent<ToggleGroup>();
toggleGroup.allowSwitchOff = true;
Toggle toggle = GetComponentInChildren<Toggle>();
toggle.isOn = true;

//可以遍历提供的迭代器 得到当前处于选中状态的 Toggle
foreach (Toggle item in toggleGroup.ActiveToggles())
{
    print(item.name + " " + item.isOn);
}
```

### 知识点四 监听事件的两种方式

#### 和Button差不多

#### 打勾或者取消打勾时触发事件

#### 1.拖脚本

#### 和Button不一样的是，函数要有一个bool参数，选择的是动态的 不是静态的

![图](images/Unity/UI系统/UGUI/Toggle拖脚本.png)

#### 函数里的bool 相当于组件参数 Is On

#### 2.代码添加

``` CSharp
//代码添加函数
toggle.onValueChanged.AddListener(toggletext2);
toggle.onValueChanged.AddListener((bo) => { print("测试3" + bo); });
//代码删除函数
toggle.onValueChanged.RemoveListener(toggletext2);
//删除所有代码添加的函数
toggle.onValueChanged.RemoveAllListeners();

public void toggletext1(bool bo) 
{
    print("测试1" + bo);
}
private void toggletext2(bool bo)
{
    print("测试2" + bo);
}
```

``` CSharp
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.UI;

public class Buttonxiti : MonoBehaviour
{
    private GameObject zd;
    public Button but;
    public Toggle toggle;
    private GameObject obj;
    void Start()
    {
        zd = Resources.Load<GameObject>("Sphere1");
        but.onClick.AddListener(() => 
        {
            obj = Instantiate(zd, transform.position, transform.rotation);
            if (toggle.isOn && obj != null)
            {
                AudioSource audio = obj.GetComponent<AudioSource>();
                Destroy(audio);
            }
        });
    }
}
```
