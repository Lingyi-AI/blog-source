## 缩放模式

### 做手游、PC 客户端通用都用这个模式
### Reference Resolution 参考分辨率 = 美术同学出图的标准分辨率
### Expand 扩展模式 保证完整显示全部 UI，不会裁切内容，可能会有黑边
### Shrink 收缩模式 保证画布完全塞进屏幕，允许裁切 UI 边缘内容，不会出现黑边
### Match Width Or Height 最常用 ，Match = 0 适合横屏游戏 ，Match = 1 适合竖屏手游，Match = 0.5 宽度高度缩放值取平均值；均衡方案。
