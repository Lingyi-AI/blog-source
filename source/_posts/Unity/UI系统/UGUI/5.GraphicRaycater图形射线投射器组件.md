### GraphicRaycaster（UI 射线） → 只检测 UGUI 元素，2D 界面
### PhysicsRaycaster（物理射线） → 检测场景 3D 物体、2D 碰撞体，和 UI 无关
![图](images/Unity/UI系统/UGUI/GraphicRaycater用来干啥.png)

### Ignore Reversed Graphics 勾选：如果 UI 被旋转 180°、Scale.x=-1 水平翻转，射线不再响应点击。取消勾选：翻转后的 UI 依旧可以被点击。
### Blocking Objects :
#### None：不被任何物体遮挡，UI 永远能点击
#### 2D Objects：场景带有 2D Collider 的精灵挡住 UI
#### 3D Objects：场景带有 Collider 的 3D 模型挡住 UI
#### All：2D+3D 物体都可以遮挡 UI
### Blocking Mask 配合上面 Blocking Objects 使用。可以指定哪些层级的物体能够遮挡 UI 射线。
