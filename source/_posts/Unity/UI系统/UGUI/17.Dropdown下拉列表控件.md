### 知识点一 DropDown是什么
DropDown是下拉列表（下拉选单）组件
是UGUI中用于处理下拉列表相关交互的关键组件

默认创建的DropDown由4组对象组成
父对象
DropDown组件依附的对象 还有一个Image组件 作为背景图

子对象
Label是当前选项描述
Arrow右侧小箭头
Template下拉列表选单

``` CSharp
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.UI;

public class UIjiemiancs : MonoBehaviour
{
    public Button but;
    public Dropdown dd;
    public GameObject obj;
    void Start()
    {
        //点击打开背包面板
        but.onClick.AddListener(() => 
        {
            beibaomianbancs.bb.gameObject.SetActive(true);
        });
        //切换黑白天
        dd.onValueChanged.AddListener((index) => 
        {
            switch (index)
            {
                case 0:
                    obj.transform.eulerAngles = new Vector3(30,0,0);
                    break;
                case 1:
                    obj.transform.eulerAngles = new Vector3(190, 0, 0);
                    break;
            }
        });
    }
}
```
