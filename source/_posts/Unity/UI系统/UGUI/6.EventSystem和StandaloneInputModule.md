### 这两个组件是UGUI 整套交互系统的入口，没有它们，Button、输入框、拖拽、点击全部失效，配合上一节的 GraphicRaycaster 构成完整 UI 输入链路。
![图](images/Unity/UI系统/UGUI/EventSystem和StandaloneInputModule主要学习内容.png)

![图](images/Unity/UI系统/UGUI/EventSystem组件用来干啥.png)

### First Selected：初始默认选中的 UI 控件。用处：键盘 / 手柄导航。
### Send Navigation Events：是否开启 UI 导航。通过wasd或上下左右键控制选中状态
### Drag Threshold：鼠标按住后，移动距离超过该像素，才判定为【拖拽】，否则判定为【点击】。
