### 知识点一 Button是什么

Button是按钮组件
是UGUI中用于处理玩家按钮相关交互的关键组件

默认创建的Button由2个对象组成
父对象——Button组件依附对象 同时挂载了一个Image组件 作为按钮背景图
子对象——按钮文本（可选）

### 知识点四 监听点击事件的两种方式

#### 点击事件 是 在按钮区域抬起按下一次 就算一次点击

#### 1.拖脚本

#### 拖的是Button按钮然后选择对应脚本的函数，不是直接拖脚本，private私有的函数找不到不能拖

![图](images/Unity/UI系统/UGUI/托脚本.png)

#### 2.代码添加

``` CSharp
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.UI;

public class Buttontext : MonoBehaviour
{
    void Start()
    {
        Button but = GetComponent<Button>();

        //代码添加函数
        but.onClick.AddListener(buttontext2);
        but.onClick.AddListener(() => { print("那么大表达式"); });

        //代码删除函数 因为那么大表达式所以不能指定删除 除非清空
        but.onClick.RemoveListener(buttontext2);

        //删除所有代码添加的函数 拖脚本的函数还在
        but.onClick.RemoveAllListeners();
    }
    public void buttontext1() 
    {
        print("测试1");
    }
    private void buttontext2() 
    {
        print("测试2");
    }
}
```
