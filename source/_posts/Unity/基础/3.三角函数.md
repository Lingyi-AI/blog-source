### 知识点一 弧度、角度相互转化

![图](images/Unity/基础/角度和弧度.png)

![图](images/Unity/基础/角度和弧度的转换.png)

``` CSharp
//弧度转角度
float rad = 1;
float anger = rad * Mathf.Rad2Deg;
print(anger);

//角度转弧度
anger = 1;
rad = anger * Mathf.Deg2Rad;
print(rad);
```

### 两个曲线类似于海浪，可以用来做船的摇摆

![图](images/Unity/基础/余弦函数(cos)曲线.png)

![图](images/Unity/基础/正弦余弦值.png)

``` CSharp
//注意：Mathf中的三角函数相关函数，传入的参数需要时弧度值
print(Mathf.Sin(30 * Mathf.Deg2Rad));//0.5
print(Mathf.Cos(60 * Mathf.Deg2Rad));//0.5
```


### 知识点三 反三角函数

![图](images/Unity/基础/反三角函数.png)

![图](images/Unity/基础/反三角函数2.png)

``` CSharp
//注意：反三角函数得到的结果是 正弦或者余弦值对应的弧度
rad = Mathf.Asin(0.5f);
print(rad * Mathf.Rad2Deg);
rad = Mathf.Acos(0.5f);
print(rad * Mathf.Rad2Deg);
```

![图](images/Unity/基础/三角函数总结.png)

![图](images/Unity/基础/三角函数习题.png)

``` CSharp
public Transform t1;
private float f;
private Vector3 v1;

void Update()
{
    print(f);
    f += 0.01f;
    v1.z = f;
    v1.x = Mathf.Sin(f) * 3;
    t1.position = v1;
}
```
