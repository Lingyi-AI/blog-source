![图](images/Unity/基础/向量加减乘除习题.png)

``` CSharp
public Transform t1;

//注意摄像机相关的内容写在LateUpdate生命周期函数中,不然可能会出现渲染相关的问题
private void LateUpdate()
{
    transform.position = t1.position + t1.up *7 - t1.forward *4;
    transform.LookAt(t1);
}
```
