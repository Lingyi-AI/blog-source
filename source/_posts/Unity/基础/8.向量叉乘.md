### 知识点二 叉乘几何意义

![图](images/Unity/基础/叉乘计算公式2.png)

假设向量 A和B 都在 XZ平面上
向量A 叉乘 向量 B
y大于0 证明 B在A右侧
y小于0 证明 B在A左侧


``` CSharp
Vector3 C = Vector3.Cross(A.position, B.position);
if (C.y > 0)
{
    print("B在A的右侧");
}
else
{
    print("B在A的左侧");
}
```
